# Landing page — surface brief

Mode: Persuade. Route: `docs/index.html` (GitHub Pages root, served from `master` / `/docs`).

## Direction contract

**THESIS** — The page is a spec card for the client, not a brochure. Every claim is a labelled row you scan in one pass, and the whole decision fits in the first viewport plus one strip. It refuses the category's alternating text-and-image scroll, and it refuses the previous build's nine evenly-ruled paragraphs.

**OWN-WORLD** — Near-black ground `#080a0e`, three inks and no grey ramp: ground, ink `#e8edf5`, field-blue `#4daafc`. Hairlines at 9% white, square corners everywhere except the two objects that are physical (the file card, the panel shot) at 14px outer. Type is the system UI face at extreme scale — 76–96px display, tracking −0.045em — set against 11px uppercase mono labels at 0.14em tracking; the two voices never meet in the middle. One fibre field of drifting blue filaments, brightest at the top-right, dissolving into the ground before the fold.

**STORY** — The visitor sees the panel and the folder in the same viewport, understands that this API client's storage is their repository, and installs the VSIX. Second read: it is a beta with honest ceilings, not a launch.

**FIRST VIEWPORT** — Full height, one centred column on a lit field, taken from the user's pinned reference (a soft blue luminous blur with a centred display serif). Top-right: three text links, no brand in the bar. Left edge, fixed: the mark and the wordmark turned on their side. Centre, in order: a tracked-caps eyebrow, the serif h1 over two authored lines, a two-line lede, one pill button that copies the install command, and the command itself in mono beneath it. The field is a CSS glow (four large radial stops, blurred once) with the ported GhostFibers canvas over it at 32% in `screen` blend, masked to fade before the lede — so the type never fights the filaments. No card, no stepper, no screenshot above the fold.

**FORM** — Superseded twice by user direction. The roll assigned grounded direction 6 of 7, the reference card (`seed: be7540a33dc10313`); the first build shipped it and was rejected as "too plain, too long". The user then pinned a reference image (Pinterest, `ef3a4094…`): a centred serif display on a soft luminous blue field. That pin wins over the roll — the composition is now the reference's, and the reference-card discipline survives *below* the fold, in the repository section, the six-cell lattice and the beta rule, which keep the restricted ink set and the hairline grid. Deliberate deviation from craft-floor: the tracked-caps eyebrow stays, because the pinned reference has one; the ban assumes a free axis and this axis is not free.

**FINISH** — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
