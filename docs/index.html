API testing that lives in your repo.

Asterisk is a local-first HTTP client for VS Code. Every request, collection and environment is a plain file you can diff, review and commit. No account, no cloud, no telemetry.

Everything the request needs

Headers, auth, bodies, assertions and a runner — in the editor you already have open.

  • Any method, any body

    JSON, text, form, multipart or binary. Content-Type is set for you.

  • Auth that sticks

    Bearer, Basic, API key, and OAuth 2.0 with automatic token refresh.

  • Environments

    {{variables}} everywhere, :path params, and {{$uuid}}, {{$timestamp}}, {{$randomInt}} per send.

  • Readable responses

    JSON tree, find with match count, timings and size, copy or save the body.

  • Scripts and assertions

    Sandboxed pre-request and test scripts. expect(response.status).to.equal(200).

  • Collection runner

    Run a folder sequentially, read the pass/fail table, feed rows from a CSV, stop on the first failure.

  • WebSocket and SSE

    One live socket per panel, a send box for WebSocket, and a log that streams events as they land.

  • Import and export

    cURL, Postman v2.1, OpenAPI 3.x in; cURL, fetch, Python, Go out.

Collections are folders. Requests are files.

Asterisk writes into .asterisk/ at the workspace root. One pretty-printed JSON file per request, so renames show up as renames and a change to an endpoint is a diff you can read in review.

  • Environments in one file, .asterisk/.environments.json.
  • Per-collection and per-folder scripts, inherited outermost first.
  • History stays in workspace storage — never committed.
repo/.asterisk/
├── .environments.json      # named environments, active one
└── My Collection/          # a collection is a folder
    └── users/list.json     # a request is a file

Assertions, not vibes.

// test script
expect(response.status).to.equal(200);
expect(JSON.parse(response.body).items).to.have.length(2);
2 passing Failures are reported, not thrown.

Every request can carry a pre-request and a test script, saved next to it and inherited from the collection. The sandbox hands you request, vars and setEnv — not process, require or the network.

Install it and paste a URL.

Not on a marketplace yet. Package it from source:

bun install && bun x vsce package

Then install the file it writes, asterisk-0.1.0-beta.1.vsix:

code --install-extension asterisk-0.1.0-beta.1.vsix
