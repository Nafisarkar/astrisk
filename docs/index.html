API testing that lives
in your repo.

Requests, collections and environments are files in the repo you already commit. No account, no cloud, no telemetry.

code --install-extension asterisk-0.1.0-beta.1.vsix

Install, and where it keeps things

STORAGE

The .asterisk folder at the workspace root: a .environments.json file, a collection folder, and one JSON file per request.

repo/.asterisk/
├─ .environments.json
└─ My Collection/
   └─ users/list.json

One pretty-printed JSON file per request. Renames are renames. An API change is a diff.

BODIES
json · text · form · multipart · binary
AUTH
bearer · basic · api-key · oauth2 + refresh
ENVS
{{variables}} · :path · system vars
RUNNER
folder run · csv rows · stop on first failure
